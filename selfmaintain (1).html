Sequence Control · Self-Holding Circuit

자기유지 기동·정지 회로와 표시등

누름버튼 스위치(Push Button Switch)와 전자접촉기(Magnetic Contactor)로 “한 번 누르면 계속 돌고, 정지를 누르면 멈추는” 회로를 구성하고, 운전·정지·과부하 상태를 표시등으로 나타냅니다. 아래 시뮬레이터의 버튼을 직접 눌러 전류 경로를 확인해 보세요.

학습 포인트 회로 시뮬레이터 동작 원리 구성 요소·실물 모듈 핵심 포인트 정리 확인 문제

01학습 포인트

이 단원을 마치면 다음 다섯 가지를 설명하고 직접 결선할 수 있어야 합니다.

CIRCUIT회로 구성

제어회로(래더 다이어그램)와 주회로를 구분해 읽고, 각 접점이 왜 직렬·병렬인지 설명한다.

PRINCIPLE동작 원리

기동 → 자기유지 → 정지 → 과부하 트립의 전류 흐름을 순서대로 추적한다.

CONTACTa접점 · b접점

PB·MC·THR의 접점 종류와 단자번호(13-14, 21-22, 95-96, 97-98)를 구분한다.

LAMP표시등 회로

MC 보조접점으로 RL(운전)·GL(정지)을, THR 접점으로 YL(과부하)을 점등한다.

SAFETY안전 기능

정지 우선 구조와 정전 후 복전 시 자동 재기동이 되지 않는 이유를 이해한다.

MCCB 2차측 R상·T상에서 퓨즈 F1·F2를 거쳐 제어회로 전원을 인출합니다. 제어회로의 MC 코일이 여자되면 주접점(1-2, 3-4, 5-6)이 동시에 닫혀 전동기가 회전합니다.

실시간 타임차트 (최근 15초)

확인해 볼 것: PB-ON 펄스가 짧게 끝나도 MC·RL은 계속 ON — 이것이 자기유지입니다. PB-OFF 펄스가 들어오는 순간 MC가 OFF되고, PB-OFF를 놓아도 다시 ON되지 않습니다.

03회로 구성과 동작 원리

“자기유지(Self-holding)”란 전자접촉기가 자기 자신의 보조 a접점으로 자기 코일의 전류 경로를 만들어, 기동 신호가 사라져도 동작 상태를 계속 유지하는 것입니다.

1

전원 투입 — MCCB ON

제어회로에 전압이 걸리지만 PB-ON(a접점)이 열려 있어 MC 코일은 무여자입니다. MC의 보조 b접점(21-22)은 평상시 닫혀 있으므로 GL(정지 표시등)이 점등됩니다.

R → F1 → MC-b(21-22) → GL → F2 → T
MCCB를 OFF/ON 해 보고 GL만 켜지는지 확인
2

기동 — PB-ON을 누름

PB-ON이 닫혀 코일에 전류가 흐르고 MC가 여자됩니다. 주접점이 닫혀 전동기가 돌고, 보조 a접점(13-14, 43-44)은 닫히고 b접점(21-22)은 열립니다. 결과적으로 RL 점등, GL 소등.

R → F1 → THR(95-96) → PB-OFF(1-2) → PB-ON(3-4) → MC 코일(A1-A2) → F2 → T
PB-ON을 누른 채로 두 갈래(PB-ON, MC-a) 모두에 전류가 흐르는지 보기
3

자기유지 — PB-ON에서 손을 뗌

PB-ON 경로는 끊기지만, 이미 닫힌 MC-a(13-14)가 PB-ON과 병렬로 연결되어 있어 우회 경로로 코일 전류가 계속 흐릅니다. MC가 스스로를 붙잡고 있는 상태입니다.

R → F1 → THR(95-96) → PB-OFF(1-2) → MC-a(13-14) → MC 코일(A1-A2) → F2 → T
버튼을 놓은 뒤 전류가 아래쪽 MC-a 경로로만 흐르는지 확인
4

정지 — PB-OFF를 누름

직렬로 들어 있는 PB-OFF(b접점)가 열려 코일 전류가 끊깁니다. MC가 소자되면서 MC-a(13-14)도 열리므로 자기유지가 해제되고, PB-OFF에서 손을 떼도 다시 켜지지 않습니다. RL 소등, GL 점등.

PB-OFF 개방 → 코일 소자 → MC-a 개방(유지 해제) · MC-b 복귀 → GL 점등
운전 중 PB-OFF를 짧게 눌렀다 떼기
5

과부하 — THR 트립

전동기에 과전류가 계속 흐르면 열동형 과부하 계전기의 바이메탈이 휘어 95-96(b)이 열리고 97-98(a)이 닫힙니다. PB-OFF를 누른 것과 같이 MC가 정지하고 YL(과부하 표시등)이 켜집니다. 원인을 제거하고 THR을 리셋한 뒤 PB-ON을 다시 눌러야 재기동됩니다.

THR 95-96 개방 → 코일 소자 → 전동기 정지 │ THR 97-98 폐로 → YL 점등
운전 중 “과부하 발생” → “THR 리셋” → 자동으로 다시 돌지 않는지 확인

정지 우선 회로 이 회로

PB-OFF가 자기유지 병렬부의 바깥(앞단)에 직렬로 있습니다. 기동과 정지를 동시에 눌러도 PB-OFF가 회로 전체를 끊기 때문에 정지가 이깁니다. 전동기 제어의 기본 원칙입니다.

기동 우선 회로 비교

PB-OFF를 MC-a와 직렬로 묶고 그 묶음을 PB-ON에 병렬로 연결한 구조입니다. PB-ON을 누르고 있는 동안에는 PB-OFF를 눌러도 꺼지지 않아, 일반 설비에서는 쓰지 않는 것이 원칙입니다.

04필요 요소와 실제 사용 모듈

실습 패널에서 흔히 쓰는 부품을 형태 위주로 단순화한 그림입니다. 각 카드의 링크로 실물 사진을 검색해 볼 수 있습니다. 단자번호는 일반적인 표기이며, 실제로는 부품 명판과 제조사 결선도를 우선합니다.

접점 용어: a접점 = arbeit contact(Make contact, NO: Normally Open, 평상시 열림) · b접점 = break contact(NC: Normally Closed, 평상시 닫힘) · c접점 = change-over contact(전환 접점). 자기유지는 영어로 Self-holding, Latching 또는 Seal-in circuit이라고 합니다.

꼭 기억할 7가지

  1. 자기유지 = PB-ON(a) ∥ MC-a(13-14)기동 버튼과 MC 보조 a접점을 병렬로 연결해야 버튼을 놓아도 코일이 계속 여자됩니다.
  2. 정지 버튼(b접점)은 직렬, 병렬부 앞단PB-OFF가 회로 전체를 끊을 수 있는 위치에 있어야 정지 우선이 됩니다.
  3. THR 95-96(b)도 코일 회로에 직렬과부하 시 자동으로 MC를 떨어뜨리고 자기유지를 해제합니다. 97-98(a)은 YL 표시에 씁니다.
  4. 표시등은 MC 보조접점으로a접점(43-44) → RL 운전, b접점(21-22) → GL 정지. 자기유지용 13-14와 다른 접점을 쓰면 회로가 명확해집니다.
  5. 정전 후 복전 시 자동 재기동 없음정전으로 MC가 떨어지면 MC-a도 열리므로, 전원이 돌아와도 PB-ON을 다시 눌러야 기동합니다. (무전압·저전압 보호 효과)
  6. 코일·램프 정격전압 = 제어전원 전압AC220V 코일에 380V를 걸면 소손, 반대로 낮으면 흡인 불량·떨림(험)이 생깁니다.
  7. MC 하나가 주접점·보조접점을 동시에 움직인다코일 여자 한 번으로 전동기 운전, 자기유지, RL 점등, GL 소등이 한꺼번에 일어납니다.

자주 하는 실수

  • 자기유지 선을 21-22(b접점)에 연결 → 전원 투입과 동시에 코일이 붙었다 떨어지기를 반복(채터링)
  • MC-a를 PB-OFF까지 감싸서 병렬 연결 → 정지 버튼이 듣지 않음
  • PB 접점 블록 NO/NC 혼동 → 정지 버튼으로 기동되거나 기동이 안 됨
  • RL·GL 접점을 바꿔 연결 → 운전·정지 표시가 반대로 점등
  • THR 95-96 대신 97-98을 코일 회로에 연결 → 평상시 기동 불가

결선·점검 순서 (실습 팁)

  1. 주회로 결선: MCCB → MC 주접점 → THR → 단자대(전동기)
  2. 제어회로 공통선: F1 → THR 95-96 → PB-OFF
  3. 코일 회로: PB-OFF → PB-ON → A1, A2 → F2
  4. 자기유지: PB-ON 양단을 MC 13-14에 병렬로
  5. 표시등: 43-44 → RL, 21-22 → GL, 97-98 → YL
  6. 전원 투입 전 회로시험기로 도통 확인 (PB-ON 누름 / MC 가동부를 손으로 눌러 자기유지 경로 확인), 이후 통전 시험

표시등 색은 국내 시퀀스 실습 관례(RL 운전 · GL 정지)를 따랐습니다. 현장이나 적용 규격에 따라 색의 의미가 다를 수 있으므로, 실제 작업에서는 도면 범례를 먼저 확인하세요.

06확인 문제

답을 떠올린 뒤 펼쳐서 확인하세요. 시뮬레이터로 직접 검증해 보면 더 좋습니다.

PB-ON에서 손을 떼도 MC가 계속 동작하는 이유는?
MC가 여자되면서 닫힌 보조 a접점 MC-a(13-14)가 PB-ON과 병렬로 연결되어 있어, PB-ON이 열려도 그 우회 경로로 코일 전류가 계속 흐르기 때문입니다.
운전 중 정전이 되었다가 전기가 다시 들어오면 전동기는?
정지 상태를 유지합니다. 정전 순간 코일이 소자되어 MC-a가 열렸으므로 복전되어도 코일 경로가 없습니다. 다시 PB-ON을 눌러야 기동합니다.
기동 버튼과 정지 버튼을 동시에 누르면?
MC는 동작하지 않습니다(정지 우선). PB-OFF가 PB-ON·MC-a 병렬부보다 앞단에 직렬로 있어 회로 전체를 끊기 때문입니다.
운전 중 THR이 트립되면 RL·GL·YL은 각각 어떻게 되나?
RL 소등, GL 점등, YL 점등. THR 95-96이 열려 MC가 소자(→ MC-a 43-44 열림, MC-b 21-22 닫힘)되고, THR 97-98이 닫혀 YL이 켜집니다.
자기유지 접점을 MC-b(21-22)에 잘못 연결하면?
전원을 넣자마자 b접점을 통해 코일이 여자되고, 여자되는 순간 b접점이 열려 코일이 떨어지는 동작을 반복합니다(채터링). 접점 손상과 소음의 원인이 됩니다.
부품 그림은 형태를 단순화한 일러스트입니다. 단자번호는 일반적인 표기이며 제조사·모델에 따라 다를 수 있으므로 실제 결선 전 부품 명판과 결선도를 확인하세요. 실습 시 반드시 전원을 차단한 상태에서 결선하고, 지도자의 확인 후 통전합니다.
