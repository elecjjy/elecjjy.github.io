01 — OVERVIEW

프로젝트 개요

실제 컨베이어벨트 설비를 PLC로 제어하는 자동화 시스템을 구현하고, 그 구조와 동작을 웹 기반 3D 콘텐츠로 시각화하여 성과를 공유합니다.

본 캡스톤디자인은 산업 현장에서 널리 쓰이는 컨베이어벨트 시스템을 PLC(Programmable Logic Controller)로 제어하는 소형 자동화 설비를 설계·구현하는 것을 목표로 합니다. 물체 감지, 모터 구동, 정지·역전 제어 등 실제 생산라인의 핵심 동작을 재현합니다.

완성된 시스템은 텍스트와 사진만으로는 구조가 전달되기 어렵다는 점을 보완하기 위해, x3dom과 three.js를 활용한 웹 3D 모델링 콘텐츠로 제작하여 팀 홈페이지에 단계별로 게시합니다.

  • HW PLC·센서·모터를 이용한 컨베이어벨트 자동제어 회로 구현
  • SW 래더 로직 기반 제어 시퀀스 설계 및 검증
  • WEB x3dom·three.js 기반 3D 모델링 콘텐츠 제작 및 게시

3D 모델링 제작 단계

완성된 컨베이어벨트 시스템을 x3dom으로 빠르게 형상화한 뒤, three.js로 정밀 모델링과 동작 애니메이션을 더해 홈페이지에 단계별로 게시합니다.

실측 · 도면화

X3DOM · 기초 형상
x3dom을 이용한 선언적 3D 목업 제작

구조 검증

three.js로 세부 형상 및 재질 표현

THEORY · LAB 05–07

보호·경보 회로 설명

경보 신호가 들어오면 릴레이 X가 자기유지하고, 온딜레이 타이머 T1·T2가 서로를 리셋하면서 경고등을 일정한 주기로 점멸시킵니다. 부저 정지 릴레이 Y는 부저만 끄고, 경보 해제 버튼 PB0은 경보 전체를 복귀시킵니다.

01래더 구성 (DC 24V, P–N)

⓪P → PL → N전원 표시
①PB0(b) → [PB1(a) ∥ X(a)] → X경보 자기유지
②X(a) → T2(한시 b) → T1소등 시간
③T1(한시 a) → T2점등 시간
④T1(한시 a) → SS(램프) → L경고등
⑤X(a) → [PB2(a) ∥ Y(a)] → Y부저 정지
⑥X(a) → Y(b) → SS(부저) → BZ부저

02동작 순서

  1. PB1을 누르면 X가 여자되고 X(a)로 자기유지합니다.
  2. X(a)를 통해 T1이 계시합니다. 이 동안 T1 한시 a접점이 열려 있어 램프는 소등입니다.
  3. T1 시간이 차면 T1 a접점이 닫혀 램프 점등, 동시에 T2가 계시를 시작합니다.
  4. T2 시간이 차면 T2 한시 b접점이 열려 T1이 리셋 → T1 a접점이 열려 램프 소등, T2도 리셋 → T2 b접점이 다시 닫혀 2번부터 반복합니다.
  5. PB2: Y가 자기유지하고 ⑥의 Y(b)가 열려 부저만 정지. 램프는 계속 점멸합니다.
  6. PB0: X 자기유지가 풀리고, X(a)를 거치는 T1·T2·Y·BZ가 모두 복귀합니다.

03점멸 시간 공식

소등 시간 = T1 설정
점등 시간 = T2 설정
점멸 주기 = T1 + T2
분당 점멸 = 60 ÷ (T1 + T2)
예) T1 = 1.0 s, T2 = 1.0 s → 주기 2.0 s, 분당 30회

04타임차트 (T1 = T2 = 1 s, 0.5 s에 경보)

05경보 모드 (선택 스위치 SS)

모드출력
C램프 점멸 + 부저
A램프만 (SS 부저 접점 개방)
B부저만 (SS 램프 접점 개방)
D경보 해제 — PB0(b) 누름

06핵심 오결선과 증상

오결선나타나는 증상
② T2 접점을 b가 아닌 a로 결선X·부저는 동작하지만 T1이 계시하지 못해 램프가 한 번도 켜지지 않음 (교착)
④ T1 접점을 a가 아닌 b로 결선경보가 없어도 램프가 켜져 있고, 경보 중엔 점등·소등 시간이 뒤바뀜
⑥ 부저를 X(a) 없이 P에 직결전원만 넣어도 부저가 울리고, 대기 상태에선 부저 정지가 듣지 않음
① 자기유지 X(a)를 PB0까지 병렬경보 해제를 눌러도 멈추지 않고 ELB를 내려야만 정지
⑤ Y 자기유지 a접점 누락PB2를 누르고 있는 동안만 부저가 멈춤

정지·해제 버튼(PB0)을 b접점으로 쓰면 배선이 끊어졌을 때 회로가 정지 쪽으로 동작하는 안전측(fail-safe) 설계가 됩니다.

3D플리커 실습 열기

EOCR(전자식 과전류 계전기)은 내장 CT로 모터의 3상 전류를 측정합니다. 설정 전류를 넘는 상태가 지연시간 동안 계속되거나 결상이 생기면 95-96(NC) 접점을 열어 MC 코일 전원을 끊고, 97-98(NO) 접점을 닫아 고장 표시등을 켭니다.

01회로 구성

주MCCB → MC 주접점 → EOCR(CT) → 모터3상 주회로
①95-96 → STOP(b) → [START(a) ∥ MC(a)] → MC운전·자기유지
②MC(a) → GL운전 표시(녹색)
③97-98 → RL고장 표시(적색)

95-96은 반드시 MC 코일 경로와 직렬이어야 합니다. 병렬이거나 빠지면 EOCR이 트립해도 모터가 멈추지 않습니다. 표시등 색은 제어반 범례를 따르며, 이 실습은 운전 녹색·고장 적색을 씁니다.

02동작 순서

  1. 전원 공급 ON, MCCB 투입
  2. START를 누르면 MC 코일에 전원 공급
  3. MC 주접점이 닫혀 모터 회전
  4. MC 보조 a접점으로 자기유지
  5. EOCR 정상: 95-96 NC가 닫혀 회로 유지
  6. 과전류 → EOCR 트립, 95-96 개방
  7. MC 코일 전원 차단 → 주접점 개방, 모터 정지
  8. 97-98 닫힘 → 적색 고장 표시등 점등 (RESET 전까지 유지)

3DEOCR 실습 열기

누전차단기(ELB)는 L로 나간 전류와 N으로 돌아온 전류의 차이만 봅니다. 차이(누설전류)가 정격감도전류를 넘으면 회로를 끊습니다. 보호접지는 고장전류가 흐를 길을 만들어 외함 전위를 낮춥니다. 둘은 서로를 대체할 수 없으며 함께 적용합니다.

01ELB 동작 원리

  1. L·N 도체가 함께 영상변류기(ZCT)를 관통합니다.
  2. 정상: IL − IN = 0 → 자속이 상쇄되어 출력 없음
  3. 누전: IΔ = IL − IN ≠ 0 → ZCT 2차 권선에 전압 유기
  4. 검출·증폭 → 트립코일 동작 → 주접점 개방
정격감도전류 IΔn = 30 mA
정격부동작전류 = 15 mA (IΔn의 50 %)
동작시간 0.03 s 이내 (고감도 고속형)
시험 버튼: 시험저항으로 ZCT를 우회시켜 불평형을 만듦

02중성선 N과 보호도체 PE

구분중성선 N보호도체 PE
역할부하전류의 귀로고장 시 보호 경로
정상 시 전류= IL≈ 0
ELB 통과통과 (ZCT 관통)통과 금지
색상 (KEC)청색녹색-노란색

ELB 부하측에서 N과 PE를 연결하면 부하전류 일부가 대지로 돌아가 불필요 트립이 생기고, N 단선·역결선 때 외함이 충전될 수 있습니다.

03TT 계통 고장전류 계산 (실습 모델)

If = U0 ÷ (Rf + RA + RB)
UE = If × RA (외함 대지전위)
U0 = 220 V, RA(기기 접지) = 10 Ω, RB(계통 접지) = 5 Ω
완전 지락(Rf ≈ 0): If = 220 ÷ 15 ≈ 14.7 A
UE ≈ 14.7 × 10 ≈ 147 V

14.7 A는 MCCB(20 A)를 즉시 동작시키지 못할 수 있고, 그동안 외함에는 위험 전압이 남습니다. 그래서 TT 계통에는 ELB가 필요합니다. 보호 조건 예: RA × IΔn ≤ 50 V (IEC 60364 기반).

04누전차단기의 한계

  • 사람이 L과 N에 동시에 닿으면 L/N이 평형이라 검출 불가
  • 감도 미만 누설(예: 10 mA)은 계속 흐를 수 있음
  • 과부하·단락은 별도 과전류 보호 필요 (겸용형 제외)
  • 고장 난 ELB는 동작하지 않음 → 정기 시험 버튼 점검

05인체 통전 전류의 영향 (개략, 교류)

~ 0.5 mA대부분 감지 못함
0.5 ~ 5 mA찌릿함 감지
5 ~ 10 mA고통, 근육 경련 시작
10 ~ 30 mA이탈 곤란, 호흡 곤란 가능
30 mA 이상통전 시간에 따라 심실세동 위험

06누전 발생 시 대응

  1. 기기·외함 접촉 금지, 주변 인원 접근 통제
  2. 상위 차단기 개방 확인 (가능하면 잠금·표찰)
  3. 감전자 발생 시 맨손으로 만지지 말고 전원부터 차단 → 119 신고 → 필요 시 심폐소생술
  4. 원인 기기 분리 후 검전기로 무전압 확인, 절연저항·접지 상태 측정
  5. 수리 후 재투입하고 시험 버튼으로 동작 확인 — 원인 확인 없는 반복 재투입 금지

인체 영향 표는 IEC 60479-1 개념을 교육용으로 단순화한 것이며, 실제 영향은 통전 경로·시간·개인차에 따라 다릅니다. 정전 작업은 차단 → 잠금·표찰 → 검전 → (필요 시) 단락접지 순서를 지킵니다.
