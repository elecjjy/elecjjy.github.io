정·역회전 인터록 결선 실습

정회전(MC1)·역회전(MC2) 전자접촉기가 동시에 투입되지 못하도록 상대 MC의 b접점으로 인터록 회로를 결선합니다. 이론과 회로도로 원리를 익힌 뒤, 아래 3D 디지털 트윈에서 직접 결선하고 전류 흐름·정상 동작·오류 상황을 체험하세요.

⚡ 전기기능사 실기 대비🧩 3D 디지털 트윈📱 모바일 VR (카드보드·WebXR)🔆 전류 흐름 시각화

학습 포인트

  • MC 2개(MC1 정회전·MC2 역회전) 구성
  • 인터록: 상대 MC의 b접점(21-22)을 자기 코일과 직렬
  • 주회로 상 교체: MC2 부하측에서 R↔T 교차

체험 오류

  • 인터록 누락 → 동시 투입 → R–T 상간 단락, MCCB 트립
  • 주회로 상 교체 오류(미교체·순환) → 역회전 불가

01

3상 유도전동기 회전 방향의 원리

전동기의 회전 방향은 고정자에 만들어지는 회전자계의 방향으로 정해지고, 회전자계의 방향은 전원의 상순(R→S→T)으로 정해집니다.

상순과 회전자계

핵심 정리

  • 3상 전원선 3가닥 중 임의의 2가닥을 서로 바꾸면 상순이 반대가 되어 역회전합니다.
  • 정·역 회로에서는 정회전 MC1이 R-U, S-V, T-W, 역회전 MC2가 R-W, S-V, T-U로 연결되도록 R상과 T상을 교체하고 S상은 그대로 둡니다.
  • 3가닥을 한 칸씩 돌려 연결(순환 교체: R→V, S→W, T→U 등)하면 상순은 그대로이므로 방향이 바뀌지 않습니다.
왜 인터록이 필요할까? MC1과 MC2가 동시에 닫히면 U 단자에는 R상(MC1)과 T상(MC2)이, W 단자에는 T상(MC1)과 R상(MC2)이 함께 연결됩니다. 즉 R상과 T상이 접촉기를 통해 직접 맞붙는 상간(선간) 단락이 일어납니다.

03

회로도 — 3D 시뮬레이터와 실시간 연동

아래 버튼이나 3D 화면에서 조작하면 두 회로도에 전류 흐름(주황 점선)과 접점 상태(초록 = 닫힘)가 함께 표시됩니다. 오류 체험 모드의 설정도 도면에 반영됩니다.

조작

주회로 (동력회로)

● LIVE
R(L1)S(L2)T(L3)전류단락
  • MCCB 2차측에서 MC1·MC2 전원측(L)을 병렬로 연결합니다.
  • MC2 부하측(T)에서 R·T를 교차해 MC1 부하측(= THR 1차측)과 연결합니다.
  • THR 히터는 주회로에 직렬, 출력은 TB2를 거쳐 전동기 U·V·W로 갑니다.

제어회로 (시퀀스 회로)

● LIVE
전류 흐름접점 닫힘인터록 접점
  • 공통: THR 95-96(b) → PB0(b) 를 거쳐 정·역 회로로 분기합니다.
  • 정회전: [PB1 ∥ MC1 a(13-14)] → MC2 b(21-22) → MC1 코일. 역회전은 대칭입니다.
  • RL·GL은 각 코일과 병렬, YL은 THR 95-98(a)로 과부하 시 점등합니다.

동작 기록

    04

    동작 순서와 타임차트

    1. MCCB ON — 주회로와 제어회로에 전원이 공급됩니다. 모든 b접점(THR 95-96, PB0, MC1·MC2 21-22)은 닫혀 있습니다.
    2. PB1 누름 — MC1 코일 여자 → 주접점 폐로(정회전), 13-14 폐로(자기유지), 21-22 개방(MC2 회로 차단 = 인터록), RL 점등.
    3. 정회전 중 PB2 누름 — MC1의 21-22가 열려 있으므로 MC2 코일에 전류가 흐르지 않습니다. 인터록 동작
    4. PB0 누름 — 제어회로 차단 → MC1 소자 → 자기유지·인터록 해제, 전동기 정지.
    5. PB2 누름 — MC2 여자 → R·T가 교체된 전원으로 역회전, GL 점등, MC2 21-22 개방으로 MC1 차단.
    6. 과부하 발생 — THR 트립 → 95-96 개방(운전 중인 MC 소자), 95-98 폐로(YL 점등). 원인 제거 후 THR 리셋 → 재기동.

    타임차트

    PB2를 처음 누른 시점(정회전 중)은 인터록 때문에 MC2가 투입되지 않습니다. 반드시 정지 → 반대 방향 기동 순서로 전환합니다.

    05

    인터록의 종류

    본 실습

    전기적 인터록 (보조 b접점)

    상대 MC의 보조 b접점(21-22)을 자기 코일 회로에 직렬로 넣습니다. 상대가 투입되면 b접점이 열려 자기 코일 회로가 끊어집니다. 정·역 회로의 기본이며 기능사 실기에서 가장 많이 출제됩니다.

    응용

    버튼 인터록 (복합 푸시버튼)

    PB1의 b접점을 MC2 회로에, PB2의 b접점을 MC1 회로에 넣어 반대 버튼을 누르는 순간 기존 MC를 끊습니다. 정지 없이 바로 전환되지만, 회전 중 역상이 걸려 큰 돌입전류와 기계적 충격이 생기므로 사용 조건을 확인해야 합니다.

    실무

    기계적 인터록

    두 MC 사이의 기계적 레버로 한쪽이 닫히면 다른 쪽이 물리적으로 닫히지 못하게 합니다(가역형 전자접촉기). 실무에서는 접점 용착 등에 대비해 전기적 + 기계적 인터록을 함께 쓰는 것이 일반적입니다.

    06

    오류 체험 시나리오

    3D 실습의 오류 체험 모드에서 아래 상황을 그대로 재현할 수 있습니다. 교육용 모의이며, 실제 설비에서 시도해서는 안 됩니다.

    ❶ 인터록 누락 → 상간 단락

    1. MC1·MC2 코일 회로에 상대 b접점 없이 바로 연결된 상태
    2. 정회전 운전 중 PB2를 누르면 MC2도 투입 → 두 MC 동시 투입
    3. 전류 경로: R → MC1(L1→T1) → U 단자 ← MC2(T3←L3) ← T
    4. R–T 사이에 부하 없이 전류가 흐르는 선간 단락 → 정격의 수십 배 이상 단락전류, 아크·접점 용착 → MCCB 트립
    진단법 — 전원 차단 상태에서 MC1을 수동으로 눌러 둔 채 PB2를 누르고, 제어회로 양단(R–T) 저항을 측정합니다. MC2 코일 저항값이 측정되면 인터록 누락입니다(정상이면 ∞).

    ❷ 주회로 상 교체 오류 → 역회전 불가

    • 미교체: MC2도 R-U, S-V, T-W → PB2를 눌러도 정회전. (동시 투입되어도 같은 상끼리 병렬이라 단락은 없음)
    • 3상 순환 교체(R→V, S→W, T→U): 상순 R→S→T가 그대로 유지 → 정회전. 동시 투입 시에는 3상이 모두 맞물려 단락.
    • 한 선 미결선(결상): 기동 불가, 웅웅거리는 소음·과열 → THR 트립.
    확인법 — 테스터로 MC2를 수동 투입한 상태에서 R–W, S–V, T–U 도통을 확인합니다. 시운전 시 전동기 축 방향(부하측에서 본 회전 방향)을 반드시 관찰하세요.
    07

    전기기능사 실기 대비

    결선 체크리스트

    전원 투입 전 테스터 점검 순서

    1. 제어회로 R–T 저항: ∞ (단락 없음)
    2. PB1을 누름 → MC1 코일 저항값 표시
    3. MC1을 손으로 눌러(수동 투입) PB1에서 손을 떼도 저항값 유지 → 자기유지 정상
    4. MC1 수동 투입 상태에서 PB2 누름 → 값 변화 없음(MC2 회로 차단) → 인터록 정상
    5. 같은 방법으로 역회전(PB2, MC2) 확인
    6. PB0을 함께 누르면 ∞ → 정지 정상 / THR 트립 버튼 → ∞ → 과부하 보호 정상
    7. 주회로: MC1 수동 투입 시 R-U·S-V·T-W, MC2 수동 투입 시 R-W·S-V·T-U 도통

    자주 하는 실수

    • 인터록에 자기 자신의 b접점을 사용 → 투입 즉시 스스로 끊김(채터링)
    • 인터록에 상대 a접점을 사용 → 반대 논리로 동작 불가
    • 자기유지 a접점을 PB와 직렬로 연결 → 기동 불가
    • 상 교체를 MC2 전원측과 부하측 양쪽에서 해서 다시 원래대로(정회전)
